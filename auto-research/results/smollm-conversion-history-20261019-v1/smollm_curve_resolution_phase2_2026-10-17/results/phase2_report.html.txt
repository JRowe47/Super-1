SmolLM2-135M — curve resolution research






EXPERIMENT 02 · FIRST TRANSFORMER BLOCK ONLY


SmolLM2-135M
Decomposition and curve resolution


84 validation configurations · 8 held-out candidates · no training · FP32 CPU inference


Structured query/key factors preserve the model's next-token distributions at substantially reduced coefficient budgets. This experiment tests the structure carried by the coefficients; the cubic-curve wrapper itself is not the source of the low-rank benefit.



Selected shared Q/K result:
 retain 55,104 of 442,368 Q/K values (12.46%), using rank 41. Held-out Δ NLL is +0.000434 nats/token, with a 95% document-bootstrap interval [-0.000056, +0.000950]. KL is 0.000285; argmax agreement is 99.11%. This removes 10.94% of the first block's linear-projection MACs, not that fraction of whole-model runtime.



Runtime limit:
 the shared-Q/K candidate's median paired latency ratio was 0.954× for the first-block measurement and 1.041× for the complete model. Full-model CPU latency was slower in this short run; no end-to-end speedup was demonstrated.




What was tested


The exact phase-1 scalar curve indexed 3,540,096 parameters in block 0. Here, query and key matrices are decomposed independently or jointly into two factors, each stored as coefficient curves. Evaluation uses exact integer knots and two matrix multiplications. Joint Q/K evaluates its shared input factor once. Query/key output coordinates, RoPE, attention heads, residual connections and cache dimensions are preserved.


We also tested coarse-to-fine Haar coefficients and uniformly thinned spline knots in flattened matrix order. These reconstruct a dense matrix once, so their reduced coefficient count does not reduce inference MACs. MLP groups retain coupled gate/up rows and down columns, using importance scores calibrated on real text, contiguous order, or three random orderings.



All 30 transformer blocks still execute.
 MLP neuron removal reduces width/contributions, not sequential depth. No gradient steps, distillation, residual rescaling, or downstream recovery training were applied. Only block 0 changes.


Held-out measurements


Each candidate was selected using validation only, then measured on 16,384 predicted tokens in 128 independent 128-token contexts. The baseline sample NLL is 3.477835. Positive Δ NLL is worse; small negative changes are not evidence of a general capability improvement. Argmax agreement compares with the original model, not with correct answers.

The exact curve control is bit-identical. Full-rank factorization changes arithmetic order, so it has small FP32 rounding differences. All tested outputs were finite. 263 parameter tensors outside block 0 were checked by hash and remained identical. For the shared-Q/K candidate, 32 incremental cached steps versus a full prefill differed by at most 0.000102519989 in logits.


Dataset and uncertainty


WikiText-2 raw, official train/validation/test article partitions. Calibration used 16,384 train tokens; selection used 4,096 validation tokens. Article-title overlap across splits was checked. Each 129-token sample stays within one article and supplies 128 shifted next-token targets. Context resets at each sample. This is a sampled, fixed-context comparison, not standard complete WikiText-2 perplexity. The test split was excluded from this experiment's calibration and selection; it may have appeared in the original model's pretraining.


The 95% intervals resample 45 sampled test documents, with all their selected windows, in 2,000 paired bootstrap replicates. They describe uncertainty on this sample, not model-family generalization. Dataset sampling has one seed per split; model weights have one pinned revision. Do not extrapolate to later layers, long contexts, instruction following, or TinyLlama without testing.


What this supports next



Retain a structured Q/K factor family as the working representation. Test its calibration stability and longer contexts before moving to TinyLlama.

For MLP reduction, test activation-aware factorization of the down projection and a small teacher-distillation or least-squares recovery step. Removing coupled neurons alone need not preserve their combined function.

To test actual depth, train a shared residual operator or continuous-depth surrogate for block 0, then compare 8, 4, 2 and 1 evaluation steps. Keep this distinct from reducing spline knots, matrix rank or MLP width.



No result here shows that raw flattened weights form a naturally smooth semantic curve, or that ordinary cubic interpolation can replace attention/MLP computation. Low-rank approximation supplies the demonstrated structure.
