SmolLM2 — Phase 6




EXPERIMENT 06 · 17 OCTOBER 2026

Initialization and longer distillation

    
Phase 5 found nearly identical quality for jointly trained curves and independent dense weights. Phase 6 therefore asks whether a different starting transformation, with more distillation, recovers the quality lost when reducing depth. This phase focuses on 28 blocks: two four-block regions each execute three blocks.

    

Fresh audit.
 Retained-native initialization reaches 1.1090× original perplexity; interpolated initialization reaches 1.1618×. The paired retained-minus-interpolated difference is -0.04651 nats/token, with a 95% document-bootstrap interval [-0.06086, -0.03041]. Full-validation fidelity-gate passes: None.

    

    
The matched comparison

Both arms train six ordinary decoder blocks with unit residual strength. The interpolated arm starts from the phase-4 Hermite samples at local coordinates 1/6, 1.5 and 17/6. The retained arm starts from original offsets [0,2,3] in each region: blocks [4,6,7] and [12,14,15], all zero indexed. Thus original blocks 5 and 13 are omitted during the reduced-depth forward pass. The retained policy was fixed before results: preserve endpoints and round the middle upward. We did not search for the best blocks to remove.

    
Only these six cloned or reconstructed blocks train: 21,240,576 values in either arm. The other 22 blocks, embeddings, head and final norm remain frozen; gradients propagate through the complete model. The original 30-block parameter tensors remain untouched so the curve can retain its original knots. The interpolated starting point inherits earlier phase-4 slope training; it is not an untrained control.

    
Each arm receives 1,800 identical ordered minibatches, two sequences per batch, context 128: 460,800 input tokens drawn from the same 1,024-window pool (131,072 input tokens). Phase 5 supplied 300 updates to its independent three-step dense weights, so this is six times the exposure for this resolution. The objective is full-distribution teacher-to-student next-token KL at temperature one. AdamW uses peak LR 0.0001, zero weight decay, global gradient clipping at one, 60 warmup updates and cosine decay to 20% of peak. There is one seed and no learning-rate search.

    
Checkpoints minimize teacher KL on the first eight validation windows, checked at 0, 300, …, 1,800 updates. The full 32-window gate requires both ΔNLL ≤ 0.05 and KL ≤ 0.05. Both complete training runs are retained in the logs, and the released weight files are the selected checkpoints.

Residual strength is a separate factor

Before training, we evaluated unit scaling and the earlier 4/3 multiplier on all 32 validation windows. Multipliers are folded into attention output and MLP down-projection matrices. The multiplier helps interpolation but harms the chosen retained-block initialization in these initial measurements. Both trained arms nevertheless use the same prespecified unit convention. This is an initialization comparison under that convention, not a search for each arm's optimal residual scale.

Exploratory matrix-norm control

After the first 300-update checkpoints, we added a validation-only diagnostic. For each sampled projection matrix, restore its Frobenius norm to the square root of the linearly interpolated squared norms of the two adjacent original matrices. Leave both RMSNorm vectors unchanged. This checks a specific scale effect; it does not change either primary training run or the audit candidates.

Can the improved models still be curves?

Yes: the three-sample derivative matrix A₃ has rank three. Define cardinal functions 
l(t)=a(t) A₃⁺
, where a(t) is the four-component Hermite derivative basis. At the three fitted sample locations these functions form the identity matrix, and at all four original knots they vanish. For each tensor, add 
Σ lᵢ(t) [Wᵢ − C₀(tᵢ)]
 to the phase-4 base curve C₀. This interpolates arbitrary learned three-block weights while retaining every original knot.

    
Phase 5 needed five sample points to cover both two-step and three-step schedules. This phase fits only three-step samples, so three cardinal components suffice. The public loader exposes only the trained three-step schedule and the original four-step schedule. Quality at two steps or other unseen schedules has not been established. This conversion uses the same 21,240,576 coefficient values as the six fitted blocks, plus the retained reference representation; it is a functionality construction without a storage-compression claim.

These are ablations of fitted models, not a randomized test that joint training caused the interaction.

Scope and next decision

This experiment compares two concrete initialization policies at a single reduced depth under one residual convention and training seed. It tests whether each selected model can be expressed as a continuous curve while preserving the original discrete model. It does not reproduce GSA's input-conditioned coefficients, hierarchical recurrent state, expert bundling or from-scratch training.

    
The next priority is whole-model adaptation at 28 blocks: clone and train every retained decoder block from the stronger phase-6 checkpoint, keeping the original 30-block model intact, then fit a global depth curve. That would directly test whether the frozen remainder limits recovery. Norm-restored interpolation remains a useful initialization control; its validation-only diagnostic does not predict its trained outcome. Further depth reduction needs its own evaluation and another reserved audit.

    
Whole-model feasibility: planning only

A global 30-knot Hermite construction can retain the original model while fitting a separately trained 28-block model. The uniform 28-sample grid has no collisions with the original knots; its 28×30 derivative sampling matrix has rank 28 and condition number 6.92. Thus the same cardinal construction can represent arbitrary weights at all 28 fitted block positions. This is an algebraic feasibility result, not an evaluated whole-model curve.

    
Training all 28 decoder blocks would expose 99,122,688 trainable values. Their FP32 weights, gradients and two Adam moments, plus all original model weights, total approximately 1.98 GiB. Activations, teacher caches, temporary buffers and framework overhead are additional; this is a lower bound, not a measured peak-memory claim.

    
The same uniform 26-sample grid hits original knots 7 and 22, leaving rank 24 for corrections. A depth-only curve cannot both preserve those knot values and assign different weights at those identical coordinates. A 26-block follow-up must keep those samples fixed or change the grid or parameterization. The tested 28-block grid avoids this issue.

    
Related work and untested mechanisms


ShortGPT (Men et al., ACL Findings 2025)
 ranks layers using input/output activation similarity and treats generation with a separate strategy. Our inference is that calibration-based block selection is worth comparing with the fixed retention policy used here. This phase does not reproduce that method.

    

Git Re-Basin (Ainsworth, Hayase and Srinivasa, ICLR 2023)
 uses function-preserving neuron permutations to align independently trained models for weight merging. Applying alignment to adjacent-layer curve construction is a separate hypothesis; these results do not identify misalignment as the cause of interpolation's losses. Both primary sources were checked on 17 October 2026.
