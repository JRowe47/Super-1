THESIS: A GEOMETRIC APPROACH TO SELF-ATTENTION
Standard self-attention keeps a key/value cache that grows with context and a
fixed set of stored weight matrices. We replace both. Function-weights (FW)
represent weights as functions rather than stored matrices, so the effective weight
at each position is computed from the geometry of the input instead of looked up.
Hierarchy replaces the KV cache with a hierarchical recurrent state — a small set
of tensors at multiple scales that summarize the sequence, so state is constant in
context. Attention becomes geometry over a compact recurrent representation
instead of a dot-product search over every past token.

WHAT IS ESTABLISHED
Controlled contract. Byte-identical data, same teacher and 0.1 CE + 1.0
forward-KL objective, same 4,883-step / 10.0M-token exposure, same AdamW
schedule and seeds; parameters matched to 0.5% (in-house) and 0.008%
(nanoGPT). Artifacts SHA-256 hashed.
Long-context reversal holds against both baselines. Hierarchy fixed CE
barely moves from 512 → 2,048 (5.26 → 5.29) while both transformers degrade
(in-house 6.29 → 10.65; nanoGPT 5.13 → 5.99).
Function-weights preserve quality. All +FW variants sit within 0.04 CE of pure
hierarchy at every checkpoint and within 0.15 at every fixed-eval context, and
lead on ARC-Easy.
Structurally cheaper. Constant 5,504-byte state; 114.1M MACs/token at any
context vs 122.7–133.9M for the transformer.
SCOPE AND NEXT STEPS
Length-extrapolation confound. Both models trained at 512 and were
evaluated at up to 2,048. nanoGPT uses learned absolute position
embeddings, so part of its 1K/2K degradation is positional extrapolation; a
baseline trained at 2,048 or using RoPE/ALiBi would isolate the architectural
effect.
Small long-context samples. 1,024 and 2,048 fixed evals use 2 batches × 1
sequence (512 uses 16 × 2); one seed, no confidence intervals. Treat as strong
directional evidence.
FW fixed evaluation is complete for Local + FW; Hierarchy + FW and
Multiscale + FW are queued for fixed eval.
Scale-up. 1B-token confirmation run in progress.
