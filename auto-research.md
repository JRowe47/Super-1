## Scientific contract for every run

Freeze a complete instance of PROTOCOL_TEMPLATE.json before execution. Fill every required field; null means unresolved, not a default. Record the protocol hash and user approval reference in RUN_REGISTRY.json.

- One primary hypothesis, named comparator, primary metric, minimum useful effect and stop/futility criteria.
- Same data content, tokenizer/vocabulary, teacher/distillation objective when applicable, training exposure, loss masking and train/selection/confirmation separation.
- Same number of LR/optimizer/schedule trials and selection opportunities per arm. Match tokens per optimizer update via declared accumulation when microbatch changes.
- At least three paired training seeds for a confirmation claim; show every seed. For small effects, propose additional seeds or a justified power analysis, not certainty from n=3.
- Separate parameter-matched, FLOP-matched and walltime-matched questions. Matching parameters and tokens does not imply matching compute. Re-size/re-profile at each context.
- Use a dense upstream nanoGPT fidelity control and a properly trained strong positional baseline (e.g. a pinned RoPE implementation), not only an undertrained or extrapolating baseline.
- For hierarchy, use contiguous training lanes and persistent state across adjacent chunks; detach only at declared BPTT boundaries. Reset at real document/split boundaries. Train state must never leak into validation. Preserve a reset-window control.
- Select checkpoints with selection data only, then freeze one configuration per seed/arm before reserved confirmation. Duplicating an evaluation checks numerical repeatability, not generalization.
- Declare chronology and reuse of every evaluation region. New selection holdout is not automatically globally unseen. Reserve a new independent dataset for transfer claims.
- Full completed token/update budgets and a terminal receipt are required for a completed comparison. Report preemptions, lost checkpoints and failed arms.

Do not turn configurable budgets, prompts or benchmark gates into unexplained hard-coded runtime heuristics.
